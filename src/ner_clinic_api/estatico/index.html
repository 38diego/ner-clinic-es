Comorbilidades de una nota clínica, cada una con su lugar en el texto

Pega una nota de evolución o de egreso. El sistema encuentra las enfermedades, dice si están confirmadas, a confirmar, negadas o son de un familiar, sugiere su código CIE-10 y calcula el índice de Charlson.

No pegues datos reales de pacientes; el texto no se guarda. Usa notas inventadas o los ejemplos: el texto se analiza y se descarta, sin quedar en registros.
